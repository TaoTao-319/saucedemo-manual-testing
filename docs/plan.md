# 测试计划

目标是验证普通购物流程，识别账号差异，并使每个测试结论能追踪到操作、输入数据与证据。

| 项目 | 内容 |
|---|---|
| 对象 | https://www.saucedemo.com/ |
| 执行日期 | 2026-10-15 |
| 环境 | Windows；Chromium 153.0.8010.12；视口 1366 × 900 |
| 执行方式 | 浏览器真实操作，Playwright 辅助断言、截图与 trace 记录 |
| 正常账号 | standard_user；TC-015 另与 performance_glitch_user 对照商品数据 |
| 异常对照账号 | problem_user、visual_user |
| 登录数据 | 公开演示密码 secret_sauce；错误密码 wrong_password |
| 结算数据 | First Name: Learner；Last Name: Tester；Zip/Postal Code: 100000 |
| 商品数据 | 背包 $29.99、车灯 $9.99；对照小计 $39.98；专项商品 Bolt T-Shirt |

范围包含登录正确与错误输入、商品加载及详情一致性、购物车增删、结算必填和成功订单。补充覆盖错误密码后重试、姓氏和邮编为空；特殊账号检查全部 6 件商品并各执行两轮独立会话。空购物车结算作为单独的负向业务规则检查，重复两次。

非空但无效的邮编、支付、库存、物流、移动端和性能指标不在本次验收范围。TC-015 仅比较商品数据，不评价 performance_glitch_user 的性能。
